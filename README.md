# Event Management System

Full-stack MERN-style event booking application with JWT authentication, CRUD APIs, React routing, MongoDB support, admin dashboard, user dashboard, and responsive UI.

## Run
### Backend
cd server
npm install
npm run dev

### Frontend
cd client
npm install
npm run dev

Create `server/.env` from `.env.example`.

Demo admin:
- Register a normal account first.
- To make it admin, set `role: "admin"` in MongoDB.
